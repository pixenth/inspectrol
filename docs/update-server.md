# Сервер обновлений

При запуске Inspectrol проверяет, не вышла ли новая версия. Если вышла, на первом экране появляется предложение
обновиться. Обновление всегда необязательное: можно продолжить работу на текущей версии.

Адрес проверки задан в `src/Inspectrol.App/AboutInfo.cs`, константа `UpdateUrl`. Если вы собираете свою версию
программы, укажите там адрес своего сервера.

## Что должен отдавать сервер

По адресу проверки сервер отдаёт JSON:

```json
{
  "version": "0.2.0",
  "url": "https://example.com/download/Inspectrol-0.2.0-setup.exe",
  "size": 45123456,
  "sha256": "b1cdad39de78e50542c8cccbd4256b993c86a6c6e98bf889a190e1677d14f6f6",
  "notes": "Что нового в этой версии"
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `version` | да | Версия, например `0.2.0`. Предложение появится, только если она новее установленной |
| `url` | да | Прямая ссылка на установщик. Только `https` и файл `.exe` |
| `sha256` | да | SHA-256 установщика, 64 шестнадцатеричных символа |
| `size` | нет | Размер установщика в байтах, проверяется после скачивания |
| `notes` | нет | Текст «Что нового», его покажут перед обновлением |

По ссылке `url` сервер должен отдавать заголовок `Content-Length`, иначе программа не примет файл.

Своя серверная часть не нужна: достаточно обычного хостинга, где лежат JSON и установщик.

## Что происходит у пользователя

1. Программа запрашивает адрес проверки. Если сервер не ответил за 15 секунд, ответил ошибкой или прислал что-то,
   что не прошло проверку, программа молча работает дальше.
2. Если версия новее, человек видит предложение обновиться и текст «Что нового».
3. Программа скачивает установщик в `%LOCALAPPDATA%\Inspectrol\Загрузки`, сверяет размер и SHA-256. Файл,
   который не совпал, удаляется и не запускается.
4. Установщик запускается с ключами `/S /RUN`, программа закрывается. Установщик ставит новую версию без окон
   и открывает программу снова.

## Как выпустить версию

1. Поднять `<Version>`, `<AssemblyVersion>` и `<FileVersion>` в `src/Inspectrol.App/Inspectrol.App.csproj`.
2. Собрать установщик, указав папку на сервере, куда он будет загружен:
   ```powershell
   .\build\release.ps1 -Makensis "C:\path\to\nsis\makensis.exe" -DownloadUrl "https://example.com/download" -Notes "Что нового"
   ```
3. Загрузить `artifacts/Inspectrol-X.Y.Z-setup.exe` на сервер.
4. Только после этого заменить JSON по адресу проверки содержимым `artifacts/update.json`.

Порядок важен: если сначала обновить JSON, программы будут скачивать ещё не загруженный файл.

## Проверка без сервера в интернете

Адрес проверки можно подменить ключом запуска и поднять простой сервер на своём компьютере. Обычный `http`
разрешён только для `localhost`.

```powershell
Inspectrol.exe --update-url=http://localhost:8080/update.json
```

## Безопасность

Программа проверяет, что файл скачан полностью и совпадает с SHA-256 из JSON. Это защищает от повреждённой загрузки,
но не от подмены: тот, кто получит доступ к серверу, сможет выложить свой установщик вместе с его SHA-256.
Следите за доступом к серверу и не теряйте домен.
