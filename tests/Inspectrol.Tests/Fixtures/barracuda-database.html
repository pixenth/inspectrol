Inspector Barracuda (обновление базы данных ) 09/09/26


 !!!!! ВНИМАНИЕ: Перед обновлением базы данных, убедитесь, что у вас установлено ПО не ниже версии 1.2.3. 
Процедура обновления базы данных:

1) Скачать файл обновления;

2) Разархивировать содержимое архива;

3) Скопировать содержимое архива на карту памяти microSD, предварительно отформатированную в устройстве (!);

4) Установить карту памяти в устройство;

5) Подключить питание устройства (обязательно!);

6) На экране появится сообщение «Обновить базу данных GPS?»;

7) Клавишами MUTE/DIM выберите «кружок» для подтверждения или «крестик» для отмены обновления;

8) В случае подтверждения появится надпись «Обновление…», дождитесь перезагрузки устройства;

9) Обновление полностью завершено, проверить текущую версию БД можно в последнем пункте меню устройства.
