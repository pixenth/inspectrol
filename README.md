# Inspectrol

Бесплатная программа для Windows, которая пошагово проводит через обновление видеорегистраторов Inspector:
прошивки, базы камер и карт eMap. Всё делается через карту памяти, без сервисных центров и ручного поиска файлов.

Программа неофициальная и не связана с производителем регистраторов Inspector. Файлы обновлений она берёт
с официального сайта Inspector.

## Что умеет

- Находит карту памяти, как только её вставили в компьютер, и по записям на ней узнаёт модель регистратора
  и версию прошивки. Если узнать не получилось, модель можно выбрать из списка.
- Показывает, что можно обновить: базу камер, прошивку, карты eMap, в любом сочетании. Проверяет, подходит ли
  обновление к текущей прошивке, и не даёт поставить то, что поставить нельзя.
- Если новая прошивка ставится только поверх промежуточной, сама добавляет промежуточный шаг.
- Скачивает файлы и проверяет, что они целые.
- Помогает сохранить записи с карты на компьютер: все, за последний день или за выбранные даты.
- Очищает карту и записывает на неё обновление, затем сверяет записанное с оригиналом.
- Даёт короткую инструкцию, что делать с регистратором в машине, и после возвращения уточняет, всё ли получилось.
- Предлагает обновить саму программу, когда выходит новая версия.

## Скачать

Готовые сборки лежат на странице [Releases](../../releases):

- `Inspectrol-X.Y.Z-setup.exe`: установщик. Ставит программу для текущего пользователя, прав администратора
  не нужно. Установленная программа сама предлагает обновиться, когда выходит новая версия.
- `Inspectrol-X.Y.Z-portable-win-x64.zip`: портативная версия. Распакуйте архив в любую папку и запустите
  `Inspectrol.exe`. Об обновлениях она только сообщает, новую версию нужно скачать самостоятельно.
- `SHA256SUMS.txt`: контрольные суммы файлов.

Установщик не подписан сертификатом, поэтому при первом запуске Windows может показать окно «Windows защитил
ваш компьютер». Чтобы продолжить, нажмите «Подробнее», затем «Выполнить в любом случае».

## Требования

- Windows 10 или 11, 64 бита.
- Регистратор Inspector, который обновляется с карты памяти, и картридер.

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet test
dotnet run --project src/Inspectrol.App
```

Посмотреть мастер без карты и регистратора можно в симуляторе. Рядом с программой откроется пульт, где выбирается,
какая карта вставлена и что на ней лежит. Настоящие диски в этом режиме недоступны.

```powershell
dotnet run --project src/Inspectrol.App -- --simulator
```

### Выпуск

Установщик собирается скриптом `build/release.ps1`. Для него нужен [NSIS 3](https://nsis.sourceforge.io).

```powershell
.\build\release.ps1 -Makensis "C:\path\to\nsis\makensis.exe" -Notes "Что нового"
```

Скрипт прогоняет тесты, публикует самодостаточную сборку (у пользователя не нужен установленный .NET) и кладёт
в папку `artifacts` установщик и `update.json` для сервера обновлений. Как устроен сервер обновлений,
описано в [docs/update-server.md](docs/update-server.md).

## Устройство проекта

| Папка | Что в ней |
|---|---|
| `src/Inspectrol.Core` | Логика без интерфейса: разбор сайта Inspector, планирование обновлений, опознание регистратора, скачивание, работа с картой, симулятор |
| `src/Inspectrol.App` | Приложение WPF: окно мастера и его страницы |
| `tests/Inspectrol.Tests` | Тесты xUnit |
| `tools/Inspectrol.Cli` | Консольная утилита для проверки каталога Inspector и архивов обновлений |
| `installer` | Сценарий установщика NSIS |
| `build` | Скрипт выпуска |

Все тексты интерфейса собраны в `src/Inspectrol.Core/Strings.resx`.
